# Huellitas Router

Aplicación didáctica de Expo Router para un consultorio veterinario. Incluye navegación por pestañas, servicios, campañas de prevención y fichas de atención con rutas dinámicas.

## Ejecutar

```bash
npm install
npx expo start
```

Las rutas viven en `src/app`: `productos/index.tsx` muestra los servicios veterinarios y `productos/[id].tsx` presenta los detalles de cada servicio. En la app puedes navegar por **Inicio**, **Prevención** y **Atención**, y abrir cualquier tarjeta para consultar la información.
