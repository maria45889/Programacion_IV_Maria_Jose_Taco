# MoviTech Router

Aplicación didáctica de Expo Router para una tienda de equipos móviles. Incluye navegación por pestañas, catálogo, promociones, garantía y fichas de producto con rutas dinámicas.

## Ejecutar

```bash
npm install
npx expo start
```

Las rutas viven en `src/app`: `productos/index.tsx` muestra el catálogo y `productos/[id].tsx` presenta los detalles de cada equipo. En la app puedes navegar por **Inicio**, **Promos** y **Garantía**, y abrir cualquier tarjeta para consultar sus especificaciones.
