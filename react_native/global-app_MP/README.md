# Huellitas Global

Aplicación Expo/React Native para explorar productos de cuidado para mascotas y armar un carrito. El catálogo y el carrito comparten un store global de Zustand con selectores y acciones para agregar o quitar unidades.

## Ejecutar

```bash
npm install
npx expo start
```

En **Productos** puedes agregar alimentos y artículos veterinarios al carrito. La pestaña **Carrito** muestra cantidades, subtotal por artículo y total; el stock disponible limita cuántas unidades se pueden agregar.
