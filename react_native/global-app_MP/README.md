# MoviTech Global

Aplicación Expo/React Native para explorar un catálogo de equipos móviles y armar un carrito. El catálogo y el carrito comparten un store global de Zustand con selectores y acciones para agregar o quitar unidades.

## Ejecutar

```bash
npm install
npx expo start
```

En **Catálogo** puedes agregar equipos al carrito. La pestaña **Carrito** muestra cantidades, subtotal por equipo y total; el stock disponible limita cuántas unidades se pueden agregar.
